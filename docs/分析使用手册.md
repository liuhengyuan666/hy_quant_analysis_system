# 分析使用手册（趋势 / 长线版）

这份手册不是讲“怎么启动程序”，而是讲：

> 你应该怎么理解这个系统里的结果，尤其是针对 **趋势、长线、MA20 / MA60 / MACD** 的使用方式。

---

## 1. 这套系统最适合拿来干什么

它最适合：

- 指数 / ETF 趋势研究
- 波段 / 长线观察
- 低频辅助决策
- 通过多个层次把“原始行情”加工成“更容易理解的信号”

它不是高频交易系统，也不是日内执行系统。

---

## 2. 这套系统的分析顺序

你可以把它理解成 6 层：

1. **行情层**：`daily_bar`
2. **指标层**：MA / EMA / MACD / RSI / ATR / VOL_MA
3. **宏观层**：market regime
4. **轮动层**：谁更强、谁在领涨
5. **策略层**：四类策略偏好评分
6. **信号层**：最终 BUY / WATCH / HOLD / REDUCE / SELL

也就是说：

> 它不是只给你一条买卖信号，而是把“为什么会有这条信号”也一层层展开给你看。

---

## 3. 你最该关注的三个核心指标

你前面已经明确偏向：

- 趋势
- 长线
- MA20
- MA60
- MACD

所以你的核心阅读顺序应该是：

### 3.1 先看 MA20 / MA60

最简单的趋势判断方法：

- **价格在 MA20 上方**：短中期偏强
- **MA20 在 MA60 上方**：趋势结构偏强
- **价格在 MA60 上方**：中期趋势没有被破坏

更理想的状态是：

> **价格 > MA20 > MA60**

这通常说明趋势是比较顺的。

### 3.2 再看 MACD

MACD 主要看三件事：

- `macd` 是否在 0 轴上方
- `macd_hist` 是否转强
- 是否出现明显背离或走弱

对趋势系统来说：

- MA 负责看“结构”
- MACD 负责看“动能”

### 3.3 最后看量能

系统里有：

- `vol_ma20`
- `vol_ma60`

量能不是你第一优先级，但它可以帮助你判断：

- 走势是否有资金支持
- 突破是不是“虚的”

---

## 4. Market Regime 应该怎么用

`Market regime` 不是用来替代个别标的判断的，
而是用来判断：

> **当前整体环境，是顺风、震荡，还是逆风。**

你可以这样理解：

- `risk_on`：更适合积极看强势方向
- `neutral`：更适合选择性观察
- `risk_off`：更适合谨慎、控制仓位、避免追高

### 你的用法建议

如果你看见：

- 个别标的很强
- 但 `regime` 明显偏差

那说明：

> 这可能是局部强，不一定是环境级机会。

所以对你这种偏长线的人来说，`regime` 的作用更像：

- **控制节奏**
- **决定是不是该积极出手**

---

## 5. Rotation（轮动）应该怎么用

`Top rotation` 不是直接告诉你“必须买谁”，而是告诉你：

> 当前市场里，哪些方向更强，哪些方向更弱。

你可以把它当作“风格和主线强度榜”。

### 对你更合适的用法

不要把 rotation 当成追涨榜。

而是：

- 如果某个方向本来就在你的观察名单里
- 它同时又出现在高位 rotation
- 并且 MA20 / MA60 / MACD 结构也好

那么这个方向就更值得重点看。

---

## 6. 四类策略偏好应该怎么理解

系统里有四类策略：

- `VALUE_LEFT`
- `TREND_PULLBACK`
- `TREND_BREAKOUT`
- `MOMENTUM_RIGHT`

### 如果你偏趋势 / 长线

最重要的是这两类：

#### `TREND_PULLBACK`

意思是：

- 大趋势还没坏
- 但价格出现了阶段性回踩
- 这是“顺趋势等回撤”的思路

这通常比纯追涨更符合长线交易者。

#### `TREND_BREAKOUT`

意思是：

- 趋势结构已经形成
- 当前处于强势突破阶段
- 更偏“确认后跟随”

### 怎么看分数

你不用执着绝对数值，主要看：

- 哪一类分数最高
- 是否明显高于其他策略
- `alignment` 是否高

如果 `alignment` 高，说明：

> 不是只有一种模型觉得它好，而是多个角度都在支持它。

---

## 7. 最终信号怎么用

最终信号不是孤立的，它是：

- 策略偏好
- 宏观环境
- 轮动强弱
- 一致性

综合后的结果。

标签大致可以这样理解：

- `STRONG_BUY`：很强的综合支持
- `BUY`：偏积极
- `WATCH`：有看点，但还不够强
- `HOLD`：维持观察或持有
- `REDUCE`：谨慎、偏减仓
- `SELL`：明显转弱或不合适继续持有

### 对你更合理的用法

你不需要见到 `BUY` 就马上动作。

你更适合这样看：

1. 先看趋势结构（MA20 / MA60）
2. 再看 MACD 是否支持
3. 再看 `regime` 是否顺风
4. 最后把 `signal` 当成综合确认层

也就是说：

> `signal` 对你来说更像“综合结论”，不是唯一决策来源。

---

## 8. Data Health 为什么重要

这个系统已经加入了数据健康检查，所以在你看趋势之前，应该先确认：

- 数据有没有缺口
- 有没有异常跳变
- provider 有没有异常
- 有些标的是不是 fallback 才拿到的数据

### 为什么这对你尤其重要

因为你看的是：

- MA20
- MA60
- MACD

这些都特别怕：

- 序列断裂
- 复权口径漂移
- 异常大跳点

所以你的分析顺序应该是：

> **先看 Data Health，再看趋势。**

现在建议再加一个动作：

> **先看 Pipeline freshness，再看 Data Health。**

原因是：

- `Pipeline freshness` 先告诉你分析链有没有跑到最新日期
- 它还能告诉你“最新那一天是不是全量完整”
- 然后 `Data Health` 再告诉你这些数据里有没有 gap / jump / provider 风险

---

## 9. 桌面端应该怎么读

### 顶部先看三个日期

- `Selected analysis date`
- `Latest available analysis`
- `Regime as-of date`

再看：

- `Pipeline freshness`
- `Data health`

如果 `Selected analysis date` 和 `Regime as-of date` 不一样，说明：

> 宏观环境还没更新到你当前看的那一天，系统是在用最近一次可用宏观数据。

这并不自动表示错误。

更准确的理解是：

- 价格 / 指标 / 信号可能已经更新到最新交易日
- 宏观因子由于发布时间滞后，只能用最近一次可用值 forward-fill

### 然后看下面四块

1. `Market regime`
2. `Top rotation`
3. `Top signals`
4. `Data health`

### 历史复盘怎么做

- 用日期选择器切到历史日期
- 看当时的 signal / rotation / regime 组合
- 对照后面的走势

这对你训练自己的趋势判断很有帮助。

---

## 10. 适合你的实际决策方式

如果你偏长线、趋势，建议你这样使用：

### 优先考虑

- MA20 / MA60 结构没坏
- MACD 不是明显死叉走弱
- `TREND_PULLBACK` 或 `TREND_BREAKOUT` 靠前
- `regime` 不是明显恶劣
- `Data health` 没严重问题

### 谨慎处理

- 纯短期冲高但 MA 结构不稳定
- `rotation` 很强但 `regime` 很差
- `signal` 好看但数据健康有明显告警
- `pipeline freshness` 显示最新日不完整

---

## 11. 一句话总结你的使用方式

如果你只记一句话，就记这个：

> **先确认数据没问题，再看 MA20 / MA60 与 MACD 的趋势结构，最后用 regime、rotation 和 signal 做综合确认。**

再补一句更完整的版本：

> **先确认 pipeline 已到最新且最新日完整，再确认数据健康没问题，最后再读趋势结构和综合信号。**

这就是这套系统当前最适合你的用法。
