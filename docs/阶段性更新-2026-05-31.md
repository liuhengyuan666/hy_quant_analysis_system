## 2. i18n 国际化成果

### 技术选型

- **vue-i18n@11**（最新稳定版）
- **@intlify/unplugin-vue-i18n**（Vite 插件，支持 `<i18n>` 块）
- **Composition API 模式**（`legacy: false`）

### 基础设施

| 文件 | 说明 |
|------|------|
| `src/i18n.js` | vue-i18n 实例配置、setLocale/getLocale、持久化回调 |
| `src/locales/zh.json` | 中文翻译（~280 个 key） |
| `src/locales/en.json` | 英文翻译（~280 个 key） |
| `src/components/LanguageToggle.vue` | 右上角语言切换按钮 |

### 翻译 key 结构（域嵌套）

```
hero.*           # Hero 区域
trust.*          # Trust 摘要
signals.*        # 信号面板
backtest.*       # 回测面板
rotation.*       # 轮动面板
regime.*         # Regime 面板
environment.*    # 环境层面板
breadth.*        # 广度面板
dataHealth.*     # 数据健康面板
recentReports.*  # 最近报告面板
usageGuides.*    # 使用指南面板
refresh.*        # 刷新 UI
refreshStages.*  # 刷新阶段名称
status.*         # 状态面板
export.*         # 导出消息
utils.*          # 工具函数回退文本
timeContext.*    # 时间上下文
```

### 格式化函数 locale-aware 化

`dashboard-utils.js` 中的 11 个格式化函数已更新：

- `formatDate()` / `formatDateTime()` — 使用 `Intl.DateTimeFormat`
- `formatInteger()` / `formatFloat()` / `formatPercent()` — 使用 `Intl.NumberFormat`
- 所有回退字符串使用 `t()` 替代硬编码

### 后端来源字符串

**仍为英文**（需 Rust 后端改动）：

- `trust.headline`
- `trust.message`
- `trust.notes`

这些字符串由 Rust 后端生成，当前未通过 i18n 翻译。前端仅对 UI 框架文本做了国际化。

## 4. 已知限制与后续工作

### 当前限制

1. **后端来源字符串未国际化**：`trust.headline/message/notes` 仍为英文
2. **两语言访问模式并存**：Vue 组件使用 `useI18n()`，工具文件直接 `import i18n`
3. **Locale 文件使用 eager import**：当前仅 2 种语言可接受；如扩展至 3+ 语言，应改用 lazy loading

### 后续可选工作

- [ ] Rust 后端 i18n 支持（trust 消息多语言）
- [ ] Locale 文件 lazy loading（`import()` 动态加载）
- [ ] 更多语言支持（日语、韩语等）
- [ ] 浏览器语言自动检测 + 用户偏好持久化
