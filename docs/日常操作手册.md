# 日常操作手册（RV1）

这份手册适合你每天快速使用系统，不讲底层原理，只讲怎么跑。

---

## 1. 第一次使用（只做一次）

### 1.1 启动数据库

```bash
docker compose -f infra/docker/docker-compose.yml up -d
```

### 1.2 初始化数据库结构

```bash
cargo run -p quant-cli -- init-storage
```

### 1.3 导入标的池

```bash
cargo run -p quant-cli -- seed-universe
```

---

## 2. 每天怎么更新分析

建议在 **收盘后** 跑一次完整流程。

### 2.1 每日三件套（推荐）

```bash
# 1. 全链路数据刷新（拉取最新数据 + 计算所有指标）
cargo run -p quant-cli -- market-refresh --to <today>

# 2. 每日分析（Integrity Gate → 信号 → 组合建议）
cargo run -p quant-cli -- daily-analysis --scope global

# 3. 导出日报
cargo run -p quant-cli -- daily-report --scope global
```

**说明：**

- `market-refresh` 按顺序执行 `ingest → indicators → macro → rotation → strategy → signals → backtests`，自动拉取最新数据
- `daily-analysis` 输出 Integrity 状态、当前信号、组合操作建议
- `daily-report` 导出 Markdown 日报到 `reports/daily-report-{scope}-{date}.md`

### 2.2 桌面端工作流（推荐）

如果你日常主要通过桌面端使用系统：

1. 打开桌面端 → 点击 `Refresh data`
2. 先看 `Trust summary`
3. 再下钻 `Pipeline freshness` 与 `Data health`
4. 确认后继续阅读 `Environment / Rotation / Signals / Backtest`
5. 需要 LLM 解读时切换到 LLM 分析面板
6. 需要留档时再导出 report

### 2.3 诊断命令（当数据异常时）

```bash
# 检查各阶段最新日期与完整度
cargo run -p quant-cli -- pipeline-dates

# 解释 latest gate 为何未推进
cargo run -p quant-cli -- explain-latest-gate

# 数据健康检查
cargo run -p quant-cli -- data-health
```

## 3. 深度分析

### 3.1 多策略独立评分

```bash
# 单标的详细归因（看四套策略各自给多少分）
cargo run -p quant-cli -- strategy-perspectives --symbol 000300 --scope cn --mode detail

# 全市场多策略排行
cargo run -p quant-cli -- strategy-perspectives --scope cn --mode scoreboard
```

**说明：**

- 当前输出四套策略的独立评分：ValueLeft / TrendPullback / TrendBreakout / MomentumRight
- 每个标的的最佳策略（best_strategy）和置信度（confidence）也会显示
- Phase 2 将支持场景化加权（短线/长线场景）

### 3.2 组合操作建议

```bash
cargo run -p quant-cli -- portfolio-decision --scope global
```

**输出说明：**

- **INCREASE**：证据建议加仓
- **MAINTAIN**：维持当前仓位
- **REDUCE**：减仓
- **AVOID**：避免当前价位入场

## 5. LLM 智能分析

### 5.1 配置 LLM（只需执行一次）

```bash
cargo run -p quant-cli -- set-llm-config \
  --base-url https://api.openai.com/v1 \
  --model gpt-4o \
  --timeout-secs 60

cargo run -p quant-cli -- set-llm-api-key --key sk-xxxxxxxxxxxxxxxx
```

### 5.2 分析

```bash
# 组合决策解读（解释引擎姿态 + 多策略矛盾点，日常推荐）
cargo run -p quant-cli -- llm-analyze --scope global --action portfolio_review

# 市场叙事 / 短线人格 / 长线人格
cargo run -p quant-cli -- llm-analyze --scope global --action market_story
cargo run -p quant-cli -- llm-analyze --scope cn --action short_term_trader
cargo run -p quant-cli -- llm-analyze --scope cn --action long_term_allocator
```

可用的 `action` 参数：
- `portfolio_review` — 组合决策解读（解释确定性引擎的组合姿态 + 多策略矛盾点）
- `market_story` — 市场叙事（今天发生了什么）
- `explain_decision` — 解释决策（为什么系统这样决定）
- `preclose_review` — 收盘前复核（组合操作建议解读）
- `risk_view` — 风险视角（风控总监视角）
- `devils_advocate` — 唱反调（质疑系统结论）
- `market_adversarial_lens` — 市场博弈视角（资金角色/流动性/筹码/预期差，`config/prompts.toml` 自定义）
- `short_term_trader` — 短线交易员人格（`config/prompts.toml` 自定义）
- `long_term_allocator` — 长线配置者人格（`config/prompts.toml` 自定义）

LLM 每次分析会自动携带：多策略评分、场景对比、数据完整性状态、共享博弈假设背景（ADR-112，标注为"供验证或反驳的假设"）、前次解读（标注为非证据背景）。

### 5.3 共享博弈假设背景（默认开启）

每次 LLM 分析前，系统确保当日"市场博弈假设背景"已生成：同一 scope 同一日期只计算一次并落盘 `workspace/llm-history/{scope}/adversarial/`，之后所有 action 自动复用——即每 scope 每天只有第一次 LLM 分析会多一次前置调用。

- **注入语义**：这是"供验证或反驳的假设背景"，不是结论。你会看到分析输出主动引用并检验博弈判断（被套资金、流动性结构、资金角色冲突等）
- **分级注入**：叙事/风控/组合类 action 注入 standard 级别（analysis_text 全文，等价 full；截断策略待 TASK-215）；`explain_decision`、`preclose_review` 只注入 compact 级摘要（防止观点污染机制解释）
- **单次覆盖**：`--adversarial full|standard|compact|none`，例如 `llm-analyze --action market_story --adversarial none` 本次关闭注入
- **全局配置**：`config/llm.toml` 的 `[llm.adversarial]`（总开关 `auto_inject`）和 `[llm.adversarial.inject]`（按 action 的级别映射）
- 返回 JSON 中的 `adversarial: {injected, level, fresh}` 字段可确认注入状态

## 6. FRED 宏观数据配置

### 6.1 查看 FRED 配置状态

```bash
cargo run -p quant-cli -- show-fred-config
```

### 6.2 启用/禁用 FRED 获取

```bash
# 启用（默认）
cargo run -p quant-cli -- set-fred-config --enabled --api-key YOUR_FRED_API_KEY

# 禁用（网络不可达时）
cargo run -p quant-cli -- set-fred-config --disabled
```

## 8. 高级参考：分步执行

> **这组命令必须按顺序执行**，不能倒序或跳过中间阶段。

```bash
# 1. 拉取日线数据
cargo run -p quant-cli -- ingest-daily --from 2026-05-19 --to 2026-05-20

# 2. 计算宏观与市场环境
cargo run -p quant-cli -- compute-macro --from 2024-01-01 --to 2026-03-16

# 3. 计算指标 / 轮动 / 策略 / 信号（通常由 market-refresh 自动覆盖）
cargo run -p quant-cli -- compute-indicators
cargo run -p quant-cli -- compute-rotation
cargo run -p quant-cli -- compute-strategy-preferences
cargo run -p quant-cli -- compute-signals
```

## 9. 注意事项

- `--quiet` 是全局选项，放在子命令之前
- 默认 `daily-report` 会在 latest gate 落后时直接失败，不再静默导出旧日期日报
- 如果确实要导出历史日报，请显式传 `--date YYYY-MM-DD`
- `compute-macro` 会重建 `macro_snapshot / market_regime / environment_snapshot`
- 如果某些 FRED 因子临时异常，系统会优先复用库里已有的宏观历史
