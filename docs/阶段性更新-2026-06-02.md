# 阶段性更新 — 2026-06-02

## LLM Desktop Integration（V4）完整落地

本轮更新完成了从 CLI-only LLM 分析到**桌面端全功能 LLM 智能分析面板**的完整集成，覆盖 6 个实现阶段、3 轮 Oracle 复核修复、MCP memory 更新。

---

## 1. 本轮工作总目标

将 V3 CLI 侧的 LLM 分析能力（`analyze-with-llm`）全面迁移到桌面端 UI，让用户**不需要输入任何命令**即可完成：

- 选择 Agent + 技能 → 触发分析
- 查看 AI 报告 + 技能路由 + 历史记录
- 并排比较不同 Agent 的分析结果
- 实时编辑 Agent Profile YAML
- 一键导出 Markdown 报告

---

## 2. 六阶段实现成果

### Phase 1 — P0 MVP：触发器 + 面板（commit `92ffb17`）

**前端组件：**

- `LlmAnalysisTrigger.vue`：Dashboard 顶部「智能分析」按钮 + Agent 下拉选择器
- `LlmAnalysisPanel.vue`：6 标签页分析面板框架

**Tauri 命令：**

- `get_llm_status` — 获取 LLM 配置状态（是否已配置、provider、model）
- `list_agent_profiles` — 列出可用 Agent profiles
- `list_skills` — 列出可用分析技能
- `analyze_with_skill` — 使用指定 Agent + Skill 分析当前 dashboard snapshot

**后端逻辑：**

- `AppContext::analyze_with_skill` — 读取 dashboard snapshot、构建 ResearchContext、调用 LLM provider
- `PlaceholderProvider` — 未配置 API Key 时的降级提供者，返回示例分析

---

### Phase 2 — P0 配置 + 导出（commit `0285c94`）

**配置 UI：**

- 空状态面板内嵌配置表单（base_url / model / api_key）
- 已配置时显示当前状态卡片
- API Key 设置优先使用 OS keyring，失败回退 SQLite（打印警告）

**导出功能：**

- `AppContext::export_llm_analysis` — 渲染 markdown 报告
- 保存到 `reports/llm-analysis-{scope}-{date}.md`
- 自动注册到 `report_snapshot`（`LLM_ANALYSIS` 类型），可在 Recent reports 中查看

**真实 LLM 调用：**

- 检测到 API Key 时自动使用 `OpenAiProvider::from_config`
- 无 Key 时降级 `PlaceholderProvider`，UI 显示黄色提示条

---

### Phase 3 — P1 类型安全 + XSS 防御（commit `e5a7284`）

**类型化 DTO（`core-domain`）：**

- `LlmStatus` — LLM 配置状态
- `AgentProfileSummary` — Agent 摘要信息
- `SkillSummary` — 技能摘要信息
- `SkillTriggerResult` — 技能触发结果（Phase 5 使用）

**XSS 三层防御：**

1. **HTML Escape** — 原始文本先 escape 特殊字符
2. **Markdown 转换** — 使用 `marked` 库转换 markdown → HTML
3. **DOMPurify 过滤** — 过滤危险标签（`script`、`iframe`、`object` 等）

**Event Bridge 统一：**

- `analyzeWithLlm` 纳入 `store.js` / `main.js` 的 `initEventBridge`
- `App.vue` 通过 `bridgeAnalyzeWithLlm` 调用，不再直接 import `llmApi`

## 5. 安全设计

| 层面 | 措施 |
|------|------|
| **API Key 存储** | 优先 OS keyring → 回退 SQLite（明文，带警告） |
| **传输安全** | 仅支持 HTTPS base_url |
| **XSS 防御** | 三层过滤：escape → marked → DOMPurify |
| **降级策略** | 无 Key 时自动使用 PlaceholderProvider，UI 显示黄色提示条 |
| **信息泄露防护** | API Key 不出现在 stdout、stderr、log、前端网络请求中 |

## 8. 已知限制与后续工作

### 当前限制

1. **后端来源字符串未国际化**：`trust.headline/message/notes` 仍为英文（与 Vue 3/i18n 迁移相同限制）
2. **LLM Provider 单一**：仅支持 OpenAI-compatible API，不支持 Claude、Gemini、本地模型
3. **不支持流式输出**：分析结果一次性返回，无逐字流式效果
4. **不支持多模态**：仅文本分析，不支持图表解读
5. **Agent Profile 无版本管理**：编辑覆盖式保存，无历史版本回退

### 后续可选工作

- [ ] 支持更多 LLM Provider（Claude、Gemini、Ollama 本地模型）
- [ ] 流式输出（SSE）支持
- [ ] Agent Profile 版本历史
- [ ] 分析结果评分 / 反馈收集
- [ ] RAG 增强（将历史报告、研究笔记纳入上下文）

## 9. 用户使用路径对比

### V3 CLI 路径（仍保留）

```bash
cargo run -p quant-cli -- set-llm-config --base-url https://api.openai.com/v1 --model gpt-4o
cargo run -p quant-cli -- set-llm-api-key --key sk-xxx
cargo run -p quant-cli -- analyze-with-llm --scope global
```

### V4 桌面端路径（推荐）

1. 打开桌面端 Dashboard
2. 点击顶部 **「智能分析」**
3. 选择 Agent + 技能
4. 点击 **「开始分析」**
5. 在 6 标签页面板查看结果
6. 一键导出或比较分析
